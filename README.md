# SA88 Landing Page

## 專案說明
這是一個針對越南市場的線上遊戲推廣著陸頁（Landing Page），主要宣傳捕魚遊戲與優惠活動，引導使用者前往註冊/登入頁面。

## 功能特色
- 自動輪播廣告圖片（Banner）
- 內嵌宣傳影片（自動播放、靜音、循環）
- 動態生成導流按鈕（註冊、登入、代理、優惠）
- 使用 MobileDetect 進行裝置偵測，針對 iPhone 與其他裝置做不同處理
- 響應式設計，適配手機與桌面

## 技術棧
- 純 HTML / CSS / 原生 JavaScript
- flexible.js（移動端適配）
- MobileDetect.js（裝置判斷）
- 無後端，靜態頁面
